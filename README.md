# csv-video-navigator

Klavye kısayollarıyla ileri-geri geçiş yapılabilen, sade arayüze sahip bir **video oynatıcı web uygulaması**.  
Videoların kaynakları bir `.csv` dosyasında URL olarak tanımlanır. Oynatma barı veya butonlar görünmez; kontrol tamamen klavyeyle yapılır.

## 🚀 Özellikler
- `.csv` dosyasından otomatik video listesi yükleme  
- **A** tuşu → önceki video  
- **D** tuşu → sonraki video  
- **Boşluk (Space)** → oynat / durdur  
- Minimal arayüz (oynatma barı yok)  
- Arka plan rengi gri-beyaz (göz yormayan ton)  
- Flask tabanlı backend, tamamen yerel veya sunucuya deploy edilebilir
